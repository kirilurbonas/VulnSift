Getting started

No scans stored yet.

Triage a scanner report, export it as JSON, then store it in the dashboard database:

vulnsift triage --input results.sarif --export json
vulnsift store --input vulnsift-output/triage-report.json

Then press Refresh. The JSON report is written to --output-dir (default ./vulnsift-output).
